# [0019] 刪除鏈結串列的倒數第 N 個節點 (Remove Nth Node From End of List)

- **難度**：Medium
- **標籤**：`Linked List` `Two Pointers`
- **刷題日期**：2026-11-17
- **複習狀態**：🟢 一次 AC

---

## 1. 題目理解與邊界條件 (Input / Output / Constraints)
* **題目目標**：給定一個單向鏈結串列的頭節點 `head`，刪除串列中**倒數第 `n` 個**節點，並回傳新的頭節點（進階要求：僅使用一次走訪 One-Pass 完成）。
* **輸入限制**：
  - 節點總數 $sz$ 範圍為 $[1, 30]$（保證串列至少有 1 個節點）。
  - $0 \le \text{Node.val} \le 100$。
  - $1 \le n \le sz$（保證 $n$ 永遠合法，不會超過串列總長度）。
* **特殊狀況 (Edge Cases)**：
  - **刪除第一個節點（`n == sz`）**：例如串列為 `[1]` 且 `n = 1`（刪除後變成空串列 `nullptr`），或 `[1, 2]` 且 `n = 2`（刪除原本的 `head`）。
  - **刪除最後一個節點（`n == 1`）**：例如 `[1, 2, 3]` 且 `n = 1`。

---

## 2. 思路演進 (Intuition & Thought Process)

### 🔴 兩次走訪法 (Two-Pass: 先計算總長度) - 初始直覺
* **直覺**：先從頭走訪整條串列一次算出總長度 $L$，再從虛擬頭節點出發走 $L - n$ 步找到目標節點的前驅並刪除。
* **瓶頸**：需要走訪串列兩次（平均讀取每個節點近 2 次），且在無法回頭重新讀取的「單向資料流（Data Stream）」場景下無法使用。

### 🟢 最佳化解法：用一快一慢兩個指標隔出指定的長度 (One-Pass 快慢雙指標 + 虛擬頭節點)
* **核心思想**：單向鏈結串列無法從尾端往回倒數，但可以利用**「一快一慢兩個指標之間保持固定的距離」**，將「從尾端往回數 $n$ 步」轉化成「固定間距的尺在串列上同步往右滑動」。
* **演算法步驟**：
  1. **設立虛擬頭節點 `dummy`**：令 `dummy->next = head`，並將快指標（`fast`）與慢指標（`slow`）同時初始化在 `dummy` 上，統一處理「刪除原 `head`」與「刪除中間節點」的邏輯。
  2. **拉開固定間距（`fast` 先走 $n$ 步）**：讓 `fast` 指標單獨往前推進 $n$ 步，此時 `fast` 與 `slow` 之間精準隔出長度為 $n$ 的區間。
  3. **維持間距同步滑動**：當 `fast->next != nullptr` 時，讓 `fast` 與 `slow` 同時每次往前走 1 步。當 `fast` 剛好停在**最後一個真實節點**時，`slow` 便會精準停在**「倒數第 $n$ 個節點的前一個位置」**（即倒數第 $n + 1$ 個節點）。
  4. **跨過目標節點刪除**：直接執行標準刪除操作（`slow->next = slow->next->next`）並釋放目標節點記憶體，最後回傳 `dummy->next`。

---

## 3. 複雜度分析 (Complexity Analysis)
* **時間複雜度**：$O(N)$ — 僅需一次走訪（One-Pass），`fast` 指標從虛擬頭節點走到最後一個節點共移動 $N$ 步。
* **空間複雜度**：$O(1)$ — 僅使用常數個指標變數（`dummy`、`fast`、`slow`、`todelete`），無額外動態資料結構空間。

---

## 4. 易錯點與盲點總結 (Key Takeaways)
* **「先隔出固定長度」的兩種等價對齊方式**：
  - **方式 A（`fast` 先走 $n$ 步，停止條件 `fast->next != nullptr`）**：結束時 `fast` 停在最後一個真實節點，`slow` 停在倒數第 $n + 1$ 個節點（目標前驅）。
  - **方式 B（`fast` 先走 $n + 1$ 步，停止條件 `fast != nullptr`）**：結束時 `fast` 走出串列停在 `nullptr`，`slow` 同樣停在倒數第 $n + 1$ 個節點。兩種寫法只要**先走的步數與迴圈終止條件成對匹配**即可。
* **統一刪除操作無需特判尾節點**：只要 `slow` 精準停在目標節點的前一個位置，無論刪除的是頭節點、中間節點還是最後一個節點（`n == 1`），一律只需執行 `slow->next = slow->next->next` 即可（當刪除尾節點時，`slow->next->next` 本身即為 `nullptr`）。
* **虛擬頭節點的必要性**：題目允許 `n == sz`（刪除 `head` 本身），若沒有 `dummy` 節點，將無法讓 `slow` 停在 `head` 的前一個位置，必須額外撰寫特殊判斷處理。ㄋ
