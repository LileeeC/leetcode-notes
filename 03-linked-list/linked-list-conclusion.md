# Linked List 總結

## 理論基礎
在[關於鏈結串列，你該了解這些！](https://programmercarl.com/链表理论基础.html)中，整理了幾個核心觀念：
- **種類**：單向（Singly）、雙向（Doubly）、循環（Circular）。
- **儲存方式**：節點在記憶體中是分散儲存的，靠指標（`next` / `prev`）串接，因此不支援像陣列一樣的隨機存取（無法用二分搜尋），但定位後增刪節點只要改指標，不用搬移資料。

---

## 核心技巧與經典題型

### 1. Dummy Head（虛擬頭節點）的重要性與使用時機
- **參考文章**：[聽說用虛擬頭節點會方便很多？](https://programmercarl.com/0203.移除链表元素.html)（對應 LeetCode 203）
- **為什麼重要**：單向鏈結串列要刪除或插入某個節點時，指標必須停在它的**前一個節點**。但原本的 `head` 前面沒有節點，如果直接操作，每次遇到要改動 `head` 的情況都要另外寫特判邏輯，很容易寫漏或發生空指標錯誤。
- **使用時機**：只要題目**有可能改變原本的 `head`**（例如刪除元素、兩兩交換節點、刪除倒數第 $N$ 個節點），就在最前面接一個 `dummyhead` 指向 `head`。這樣一來，原本的 `head` 就會變成普通的中間節點，所有節點都能用同一套指標邏輯處理，最後只要回傳 `dummyhead->next` 就好。

### 2. Linked List 的基本操作
- **參考文章**：[一道題目考察了常見的五個操作！](https://programmercarl.com/0707.设计链表.html)（對應 LeetCode 707）
- 這題一次把所有基礎操作（`get`、`addAtHead`、`addAtTail`、`addAtIndex`、`deleteAtIndex`）實作了一遍。
- 不管是用單向還是雙向鏈結串列，核心都是搭配 `dummyhead`（雙向可再加 `dummytail`）與維護串列長度 `size`。只要搞清楚定位前驅節點的步數、邊界條件（插入可等於 `size`，刪除必須 `< size`），以及修改指標的先後順序避免斷鏈，基本操作就不會有問題。

### 3. 反轉 Linked List（迭代與遞迴）
- **參考文章**：[聽說過兩天反轉鏈結串列又寫不出來了？](https://programmercarl.com/0206.翻转链表.html)（對應 LeetCode 206）
- 反轉鏈結串列有兩種做法：
  - **迭代法（雙指標 `prev` / `curr`）**：空間複雜度 $O(1)$，實務上最推薦。重點在於進迴圈第一時間要先用 `tmp` 存下 `curr->next`，再把 `curr->next` 指回 `prev`，接著同步推進 `prev` 和 `curr`。
  - **遞迴法**：先一路遞迴探底抓出新的頭節點 `newHead`，再趁函式層層退回（Unwind）時由後往前反轉指標（`head->next->next = head`），並記得把 `head->next` 設為 `nullptr` 避免形成環。

### 4. 雙指標進階應用（刪除倒數節點、相交、環形）
- **刪除倒數第 N 個節點**：[刪除鏈結串列倒數第 N 個節點，怎麼刪？](https://programmercarl.com/0019.删除链表的倒数第N个节点.html)（對應 LeetCode 19）
  - 結合 `dummyhead` 與快慢雙指標，讓 `fast` 先走 $n$ 步隔出固定距離，再跟 `slow` 同步往後走，等 `fast` 走到尾端時，`slow` 就會剛好停在目標節點的前一個位置，只要走訪一次（One-Pass）就能刪除。
- **鏈結串列相交**：[鏈結串列相交](https://programmercarl.com/面试题02.07.链表相交.html)（對應面試題 02.07 / LeetCode 160）
  - 利用雙指標尋找兩條串列的交點（注意要比對的是**節點記憶體位址相同**，而不只是節點數值 `val` 相等）。
- **環形鏈結串列**：[環找到了，那入口呢？](https://programmercarl.com/0142.环形链表II.html)（對應 LeetCode 142）
  - 分兩階段：先用 `fast`（走 2 步）與 `slow`（走 1 步）在環內相遇確認有環；接著派兩個指標分別從 `head` 和相遇點出發、每次各走 1 步，根據步數等式推導，兩者最終一定會在環的入口相遇。
